# Indian Banking Transactions - Sales Dashboard

## 📌 Project Overview

The **Indian Banking Transactions - Sales Dashboard** is an Excel-based data analytics project designed to analyze banking transaction data and provide meaningful business insights through an interactive dashboard.

The project focuses on understanding transaction patterns, payment methods, customer activity, branch performance, regional performance, and transaction amounts.

## 🎯 Problem Statement

Banking transaction data contains valuable information about customer activity, transaction amounts, payment methods, branches, and regions. However, raw data can be difficult to analyze directly.

The objective of this project is to clean and transform the raw banking transaction data, analyze it using Pivot Tables, and create an interactive Excel dashboard that helps users understand important transaction trends and business performance.

## 🎯 Objectives

* Clean and prepare the banking transaction dataset.
* Analyze transaction data using Excel.
* Create Pivot Tables for detailed analysis.
* Develop meaningful KPIs.
* Build an interactive dashboard.
* Identify important business trends and patterns.
* Provide data-driven business recommendations.

## 🔄 Project Workflow

1. **Data Collection**

   * Imported the Indian banking transaction dataset.

2. **Data Cleaning**

   * Checked missing values and data consistency.
   * Cleaned and prepared the data for analysis.

3. **Data Transformation**

   * Created required calculated fields and transformed the data for analysis.

4. **Pivot Table Analysis**

   * Created Pivot Tables to analyze transactions by different dimensions such as branch, region, payment mode, and time period.

5. **KPI Creation**

   * Created key performance indicators to provide a quick overview of banking transaction performance.

6. **Dashboard Development**

   * Designed an interactive Excel dashboard using charts, KPIs, and slicers.

7. **Insights & Recommendations**

   * Analyzed the dashboard results and identified useful business insights.

## 📊 Dashboard Analysis

The dashboard provides insights into:

* Total Transaction Amount
* Total Transactions
* Total Customers
* Total Branches
* Payment Modes
* Regional Performance
* Branch Performance
* Monthly Transaction Trends
* Transaction Categories

## 💡 Key Insights

* Identified transaction trends across different time periods.
* Compared transaction performance across branches and regions.
* Analyzed the contribution of different payment modes.
* Identified areas with higher transaction activity.
* Evaluated customer transaction patterns.

## 📈 Business Recommendations

* Focus on regions and branches with higher transaction activity.
* Promote efficient and popular digital payment methods.
* Monitor low-performing branches and identify opportunities for improvement.
* Use monthly transaction trends for better business planning.
* Improve customer engagement based on transaction behavior.
* Continue monitoring transaction patterns through regular dashboard analysis.
